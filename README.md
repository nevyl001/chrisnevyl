# Chris Nevyl — Portfolio

Portafolio personal single-page con **Vite + React**, CSS Modules, **Motion** y **lucide-react**.

## Desarrollo

```bash
npm install
npm run dev
```

## Producción

```bash
npm run build
npm run preview
```

## Contenido

Todo el texto y datos viven en `src/data/info.js`.

## Estructura

```text
src/
  data/info.js
  lib/hooks.js
  lib/motion.js
  styles/base.css
  styles/animations.css
  components/
    ui/AnimatedAuroraBackground.*
    Nav/
    Hero/
    About/
    Projects/
    Experience/
    Skills/
    Education/
    Contact/
    Footer/
  App.jsx
  main.jsx
```
