# Chris Nevyl — Portfolio

Portfolio personal de una sola página con **Vite + React** y **CSS puro** (sin Tailwind).

## Desarrollo

```bash
npm install
npm run dev
```

## Producción

```bash
npm run build
npm run preview
```

## Contenido

Todo el texto y datos viven en `src/data/info.js`.

## Estructura

```text
src/
  data/info.js
  components/
    Nav.jsx
    Hero.jsx
    About.jsx
    Experience.jsx
    Projects.jsx
    Contact.jsx
    Footer.jsx
  App.jsx
  App.css
  main.jsx
```
